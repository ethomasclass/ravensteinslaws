# Ravenstein's Laws · Data Lab

The whole lab is in `index.html`.

1. Open https://github.com/ethomasclass/ravensteinslaws
2. Click **uploading an existing file** (or **Add file → Upload files**), drag in `index.html`, and click **Commit changes**.
3. Go to **Settings → Pages**. Set Source to **Deploy from a branch**, Branch **main**, folder **/ (root)**, and click **Save**.
4. After a minute or two the lab is live at **https://ethomasclass.github.io/ravensteinslaws/**

Notes
- Photos and locator maps load from Wikimedia Commons (commons.wikimedia.org / upload.wikimedia.org). If your school filter blocks those, ask IT to allow them.
- Use the arrow keys or click to move between slides.
